    What a queue server would receive

    
        
    
          This page has no backend — the queue lives in src/farm_store.js. But the payload above is
          built by the same function that would post it (prepareJob()), so it is exactly what would
          go over the network: G-code text and three numbers. The model, its vertex buffer and its filename
          never leave the tab.

          That is the architecture this demo argues for: the backend is a control plane — queue, printer state,
          file storage — and never a compute plane. Add printers and it does not get busier. Here it is a 130-line
          module in the page; swap it for a server and every call site is already shaped like an HTTP request.
